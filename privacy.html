Privacy Policy

Hermes Classroom · Last updated 16 November 2026

Hermes Classroom is a personal tool used by a single student to receive reminders about their own Google Classroom work. This policy explains what data it accesses and how that data is handled.

Data accessed

With the student's consent, and read-only, Hermes Classroom accesses:

  • The names of the student's active classes (classroom.courses.readonly).
  • The student's own coursework: titles, instructions, due dates, attachment titles, and whether each item has been turned in (classroom.coursework.me.readonly).
  • Class announcements from the last few days (classroom.announcements.readonly).

It does not access grades of other students, rosters, email, or any other Google service.

How the data is used

  • Only to build short deadline summaries and study reminders for the same student.
  • Summaries may be processed by the AI model provider configured by the student (currently OpenAI) solely to write the reminder text.
  • Reminders are delivered only to the student's own private chat.

Storage and retention

  • The OAuth token and a cached summary of the latest fetch are stored on the student's own private server with owner-only file permissions.
  • The cached summary is overwritten on each daily fetch.
  • Revoking access deletes nothing in Google Classroom; the student can delete the server copy at any time.

Sharing

Data is never sold, never used for advertising, and never shared with anyone other than the AI model provider mentioned above. Hermes Classroom's use of information received from Google APIs adheres to the Google API Services User Data Policy.

Revoking access

Access can be removed at any time from myaccount.google.com/permissions.
